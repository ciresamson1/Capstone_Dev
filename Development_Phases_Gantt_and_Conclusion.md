## B. Conclusion Format (Manuscript-Ready)

### Conclusion

This capstone project successfully developed **CapstoneV3**, a role-based project management system that supports collaboration among administrators, project managers, department managers, and clients. The system addressed the identified operational needs by implementing core modules for authentication, project and task management, threaded task comments, reactions, notifications, activity tracking, and report generation.

The development process followed an iterative and incremental approach, allowing the team to deliver high-priority features first, then improve system quality through integration and testing cycles. This approach helped ensure alignment with user requirements while minimizing implementation risks.

Based on functional verification and role-based access validation, the system met its primary objectives: improving project visibility, organizing task workflows, and strengthening communication between stakeholders. Overall, CapstoneV3 demonstrates that a structured, role-aware web platform can enhance coordination, accountability, and timely decision-making in project execution.

### Recommendations (Optional Follow-up Paragraph)

For future enhancement, the researchers recommend adding advanced analytics dashboards, automated deadline alerts, richer audit reporting, and broader test coverage for long-term maintainability and scalability.
